1. PENJELASAN DESAIN
   **CLASS**
   untuk class yang di gunakan hanya ada satu class, dimana semua class dalam 4 bahsa pemrograman memiliki nama class yang sama.
   **ATRIBUT**
   atribut class dalam 4 bahasa pemrograman yang di gunakan juga sama yaitu: idBioskop, Popcorn, Softdrink dan WaktuBuka.
   untuk atribut sendiri memiliki peran masing masing dimana :
   - idBiokop itu menunjukan id setiap bioskop yang unik, setiap objeknya
   - popcorn adalah rasa popcorn yang dimiliki oleh setiap objek bioskop bisa sama atau berbeda
   - doftdrink adalah minuman yang terdapat pada objek setiap bioskop bisa sama atau berbeda
   - waktuBuka, ini menunjukan objek bioskop jam berapa mulai di buka
   **METHOD**
     untuk method sendiri hanya ada setter dan getter untuk setiap bahasa pemrograman. ada 4 getter dan 4 setter sama seperti banyaknya atribut yang di gunakan ada class bioskop
   **ENKAPSULASI**
     pada sorcecode ke 4 bahasa pemrograman terdapat enkapsulasi, dimana atribut tidak bisa di akses di main. maka di sediakan getter untuk ambil data dari atribut dan setter untuk set atau ubah data pada atribut

2. FLOW CODE
   1. run program (mulai program)
   2. membuat satu atau lebih objek menggunakan class
   3. setelah objek di buat maka objek tersebut akan di add ke array, yang nantinya array tersebut akan berisi kumpulan objek bioskop
   4. untuk di program yang saya gunakan setelah buat objek dan add ke array, selanjutnya adalah tambah data, user akan input id bioskop, rasa popcorn, softdrink, dan waktu bukan bioskop
   5. lalu selanjutnya cari bioskop, user akan input id bioskop dan melakukan perulangan melibatkan getter untuk mencari id nya, jika di temukan maka data di tampilkan
   6. menampilkan data bioskop
   7. hapus data, user akan di minta input id bioskop lalu nanti akan di lakukan perulangan melibatkan getter untuk membandingkan data id bioskop, lalu jika ketemu maka data tersebut di hapus
   8. menampilkan data setelah ada data yang di hapus
   9. ubah data, user akan input id bioskop yang datanya ingin di ubah, lalu di lakukan perulangan melibatkan getter, kalau data ketemu maka user harus input rasa popcorn doftrdring dan waktu buka yang baru.
